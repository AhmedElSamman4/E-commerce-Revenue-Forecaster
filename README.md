# Linear Regression Training Project: E-commerce Customers

## 🎯 Project Objective

This is a training project designed to demonstrate how Linear Regression can be used to make data-driven business decisions.

The dataset is synthetic and is used for educational purposes only.

Imagine an e-commerce company wants to decide where to focus its efforts: improving the **mobile app experience** or the **website experience**.

Our goal is to analyze customer behavior and build a Linear Regression model that predicts **Yearly Amount Spent** based on customer characteristics and usage patterns.

## 📊 Dataset

The dataset is available on Kaggle:
[E-commerce Customer Device Usage](https://www.kaggle.com/iyadavvaibhav/ecommerce-customer-device-usage)

It contains information about e-commerce customers, including:

- **Avg. Session Length** — Average duration of the customer's in-store-style advice sessions.
- **Time on App** — Average time spent using the mobile app, in minutes.
- **Time on Website** — Average time spent on the website, in minutes.
- **Length of Membership** — Number of years the customer has been a member.
- **Yearly Amount Spent** — The target variable representing the customer's yearly spending.

> **Note:** The customer information in this dataset is synthetic and does not represent real individuals.
